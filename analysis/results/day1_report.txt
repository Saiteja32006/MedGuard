    decision        safe  conflict
    SAFE             423        86
    UNCERTAIN          0         0
    ABSTAIN            0       752

  SCORING CONVENTION TO STATE IN THE PAPER:
    ABSTAIN   = positive detection (true positive if conflict present)
    UNCERTAIN = counted as positive detection (defers to human review)
    SAFE      = negative prediction
    Macro-F1 averages F1(conflict) and F1(safe).

  WHY UNCERTAIN IS ALWAYS 0:
    v1 set tau = 0.5 * min(positive conflict score), so min_conflict = 2*tau.
    Every real conflict therefore scores >= 2*tau > tau -> ABSTAIN.
    Every safe case scores exactly 0 -> SAFE.
    The band [tau/2, tau) is unreachable BY CONSTRUCTION, not empirically empty.

  KEY POINTS FOR THE REBUTTAL:
   1. The score is a STEP FUNCTION, not a gradient. C changes
      discontinuously as a value crosses a threshold; between thresholds
      it varies only through NumDist.
   2. Where a drug has TWO thresholds (metformin: <30 major, <45
      moderate) there is an intermediate plateau -- eGFR 30-45 still
      flags, correctly, as a dose-reduction case. Worth reporting: the
      system is more clinically granular than the binary labels admit,
      and this is why it produced a 'false positive' at eGFR 44.6 that
      was in fact correct.
   3. Outside every threshold, C is EXACTLY 0. There is no small-but-
      nonzero region, so nothing can land in the UNCERTAIN band.

A4  MEASUREMENT-NOISE ROBUSTNESS   -> Jn3J Q1 'measurement noise'
========================================================================================
  draws: 100   assay CV: eGFR 6.5%, creatinine 6.5%, potassium 2%, INR 10%, ALT 10%, glucose 4%, WBC 5%, platelet 5%
  mean cases whose threshold verdict flips: 52.1 (3.3% of 1576)
  range: 36 .. 72

  INTERPRETATION (this is the answer to Jn3J):
    Noise does NOT smear safe scores off zero. A perturbed value either
    crosses its threshold (rule fires, C jumps to a large value) or does
    not (C stays exactly 0). Scores are quantized by the rule structure,
    so tau_hat is unaffected; what changes is which side of the boundary
    a near-threshold case falls on. The exposure is concentrated entirely
    in near-boundary cases -- see A3.
